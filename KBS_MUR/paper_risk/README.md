# paper_risk: the independent KBS manuscript

This directory holds the manuscript that is being prepared for *Knowledge-Based
Systems* as a standalone contribution. It is deliberately different from the
MUR line (`../paper`, `../../TKDE_MUR`, `../../PAMI_MUR`).

## Question

When is a marginal-utility estimate reliable enough to act on? The manuscript
studies risk-controlled selective context routing: the router scores
candidates, calibrates a decision threshold on deployment states by conformal
risk control, and abstains or stops whenever no candidate can be certified.

## What is new here

- **Decision object.** A harmful-selection budget instead of a utility
  prediction: `R = E[a(z) * 1{m(j|A) < 0}] <= alpha`, with coverage, harmful
  share, and abstention as the reported quantities.
- **Method.** RC-MUR: a calibrated gate on top of a scorer, with a mass-control
  rule and a share-control rule, plus a stopping rule for sequential routing.
- **Analysis.** Harm-budget guarantee, selective-risk corollary, a proposition
  showing why interval certification collapses when the estimation error
  dominates the estimated quantity, and a shift margin for threshold transfer.
- **Evidence.** Controlled harm ladder; deployment-state calibration on six
  traffic benchmarks; cross-dataset and cross-run threshold transfer; the
  risk--coverage frontier of the scorer; end-to-end selective routing.

## Build

```bash
latexmk -pdf -interaction=nonstopmode -halt-on-error main.tex
```

## Reproduce the numbers

```bash
cd ..
python scripts/analyze_risk_control.py    # writes results/derived/R200_risk_control
python scripts/build_risk_tables.py       # writes paper_risk/tables
```

The risk analysis reads the saved deployment traces of the multi-target runs
(`results/raw/R080b_*/*/target*_seed*/diagnostics.npz`) and the controlled harm
ladder (`results/raw/R200_harm_ladder_*`). No number in the manuscript is
transcribed by hand.
