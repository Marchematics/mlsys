# Baseline comparison matrix

Generated by `scripts/build_baseline_matrix.py` from
`paper/tables/tab_deployable.tex`, which in turn is built from the run
sets `R080b` (learned policies), `R202` (content-based subset rules) and
`R206` (fixed-set acquisition rules). Values are prediction gains
averaged over 32 fixed targets per dataset and three independent runs;
the harm rate is the per-episode negative-transfer rate. *Response at test*
records whether the policy evaluates the frozen predictor while it selects on
a test episode; *offline tuning* records what it is allowed to use before
that, where the validation-based rules do use the predictor on held-out
episodes.

## Reference points (not deployable)

| Policy | Definition | Role |
|---|---|---|
| Standalone oracle | ranks candidates by the true standalone marginal $u(j\mid\emptyset)$ | reference for the value of the first selection |
| Sequential oracle | recomputes the true marginal after every selection | upper bound on state-conditioned selection |

## Coverage of the design space

| Design decision | Policies that isolate it |
|---|---|
| informative content (similarity) | Relevance |
| diversity | MMR, DPP greedy |
| coverage | Facility location, Facility location + relevance |
| clustering | k-center, Cluster-based selection |
| standalone outcome value | Standalone Utility |
| state conditioning without the response | Cached-only router |
| offline tuned set (no per-episode decision) | Greedy validation set, Adaptive-$k$, Two-step lookahead, Gradient influence |
| state conditioning with the response | R-MUR |

## Gaps

- `k-center` and `Relevance` have no dedicated single reference in the
  bibliography; they are reported as classical rules of their families.
- `Cluster-based selection` and `Two-step lookahead set` are cited to
  arXiv records because the retrieved metadata did not state a venue.
- RankRAG, GenICL, Learning to Cut and Dynamic Feature Graph are cited for
  positioning only; they are not implemented as baselines.
