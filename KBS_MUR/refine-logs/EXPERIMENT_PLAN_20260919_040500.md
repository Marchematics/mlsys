# Experiment Plan

**Problem**：在候选辅助知识池和有限 budget 下，选择相对于当前 selected set 仍能降低 end-task loss 的 contexts，并在继续取用知识无可信正收益时停止。

**Method Thesis**：MUR-light 从缓存 embeddings 学习任意非空状态下的 counterfactual loss marginal `m(j|A)`，通过 sequential re-scoring 与 calibrated intervals 实现低成本选择和停止。

**Date**：2026-09-19

## Claim Map

| Claim | Why It Matters | Minimum Convincing Evidence | Linked Blocks |
|---|---|---|---|
| C1: set-conditioned marginal utility is necessary under redundancy | 若 `u(j|empty)` 已足够，MUR 没有独立贡献 | relation-positive stress 中，MUR-light 相对 Hashimoto/Static 与 coverage baseline 的 utility recovery 优势随 redundancy 增强，paired CI 排除 0 | B1, B2 |
| C2: calibrated sequential stopping improves the gain–harm/cost frontier | 单纯提高预测分数不能证明 reliable routing | harmful fraction、K、B 变化时，MUR-light 在 matched gain 下减少 negative transfer 或在 matched harm 下提高 gain，并保持 calibration coverage | B3, B4 |

**Anti-claims to rule out**：增益仅来自更多参数；仅来自 prediction-delta expert calls；仅来自 diversity penalty；仅来自固定选择更少 contexts；来自 target leakage 或同一 expert/outcome 重用。

## Paper Storyline

- **Main paper must prove**：C1、C2；MUR-light 的端到端成本；Electricity 外部方向性复现；closest-work baseline ladder。
- **Appendix can support**：MUR-full、ranking loss、cross-fitting、conditional submodular diagnostics、更多 thresholds、完整 per-seed 表。

## Shared Protocol

### Data partitions

每个数据集固定 `expert-train / router-label / calibration / test` 四分区。expert 只在 `expert-train` 拟合一次，之后永久冻结。router labels 只来自 `router-label`；interval radius 和 stop threshold 只来自 `calibration`；test 只使用一次。所有 split 以 entity 和时间为最小隔离单元。

### State construction

训练 states 混合四种来源：uniform random subsets、relevance prefixes、static-utility prefixes、oracle prefixes。每条缓存记录包含 expert hash、episode ID、candidate IDs、subset bitmask、state source、loss before/after、cost、label、feature version 和生成时间。

### State-shift gate

在 validation rollout 上按 state source 和 `|A|` 报告 MAE 与 interval coverage。若 deployed-prefix coverage 比 nominal 低超过 3 percentage points，或 deployed-prefix MAE / random-state MAE > 1.25，则允许一次 train-only on-policy augmentation；之后重新训练、重新 calibration，再冻结进入 test。不得迭代多轮。

### Seeds and inference

- Synthetic 与 Electricity 正式门控：3 seeds；结论以 episode-paired bootstrap CI 为主，seed 作为 block。
- 任何 stochastic expert 额外固定 expert seed，避免 router 与 expert seed 混淆。
- 报告 MUR-light online router calls、online expert calls、latency、peak memory、selected-context cost。

### Baseline families

1. **No/naive transfer**：Base-only、Pool-all/forced-B。
2. **Static selection**：Similarity/Relevance、Hashimoto normalized Incremental Utility、Static Utility、MMR/Set-Coverage。
3. **Dynamic decision**：MUR-light、MUR-full diagnostic、Oracle Greedy。

## Experiment Blocks

### B0: Contract, oracle headroom, and leakage sanity

- **Claim tested**：任务存在可路由 headroom，labels 与 features 可在不泄漏 target 的条件下生成。
- **Why**：没有 oracle headroom 时，任何 router 结论都无意义。
- **Dataset/task**：controlled synthetic default `K=8,B=2`; Electricity smoke `K=8,B<=2`。
- **Systems**：Base-only、Pool-all、Oracle Greedy。
- **Metrics**：base loss、oracle gain、fraction positive/negative marginals、duplicate marginal decay、feature target-access audit、split overlap count、expert-call count。
- **Setup**：1 seed、2k train/512 calibration/1k test episodes；CPU 或单 A10G；完整 provenance。
- **Success criterion**：oracle gain > 0；至少 15% test states 同时存在 positive 和 nonpositive remaining candidates；高 redundancy 下 second duplicate median marginal 小于其 standalone marginal 的 25%；split overlap=0；任何 inference feature 不读取 `y`。
- **Failure interpretation**：重设计 generator/candidate construction 或 expert；不得通过加大 router 隐藏无 headroom。
- **Target**：Table 1 protocol audit；appendix distribution plot。
- **Priority**：MUST-RUN。

### B1: Gate A — outcome utility versus relevance

- **Claim tested**：end-task utility target 比 relevance 更接近最终选择决策。
- **Dataset/task**：synthetic default `K=8,B=1`, redundancy=0.25, harmful fraction `{0,0.25,0.4}`。
- **Systems**：Relevance、Hashimoto normalized Incremental Utility、Static Utility、Oracle one-step。
- **Metrics**：prediction loss、utility recovery、useful-selection precision、NTR、utility MAE/rank correlation。
- **Setup**：3 seeds；同 backbone/parameter budget；Static/Hashimoto 只看 `A=empty`；每个 setting 5k test episodes。
- **Success criterion**：Static Utility 对 Relevance 的 paired utility-recovery improvement >=0.05 且 95% CI 下界 >0；NTR 不恶化超过 2 percentage points。Hashimoto normalization 与 unnormalized Static 的差异单独报告。
- **Failure interpretation**：utility labels或 expert response 不可预测；停止后续 KBS 故事并诊断，不直接推进 MUR。
- **Target**：Figure 1C / Gate A mini-table。
- **Priority**：MUST-RUN。

### B2: Gates B and N — nonempty-state novelty stress

- **Claim tested**：当候选 standalone utility 均为正且 relation 均为正时，只有 set-conditioned utility 能在选入一个 context 后识别 redundancy 并重新排序。
- **Dataset/task**：relation-positive synthetic；`K in {4,8,16,32}`，主点 `K=8,B=2,r=.5`；redundancy ratio `{0,.25,.5}` 在 K=8 上运行，high-redundancy `.75` 使用 `K=16,B=2`，确保至少四个 unique groups，避免 coverage 因 unique-group count 等于 budget 而退化为 oracle；group payoff heterogeneous；无 harmful candidates 的 positive-control 主图，另加 0.2 harmful sensitivity。
- **Systems**：Hashimoto normalized Incremental Utility、Static Utility、MMR/Set-Coverage、MUR-light；Oracle Greedy 仅作上界。MUR-full 放 appendix。
- **Metrics**：utility recovery、prediction loss、duplicate-selection rate、useful-selection precision、step-2 regret、average contexts、latency。
- **Setup**：3 seeds；MUR-light 与 Static 使用相同 encoder/hidden size；Huber-only primary；ranking-loss variant appendix。
- **Success criterion**：在 `K=16,B=2,redundancy=.75` 时 MUR-light 相对 Static utility recovery >=0.05、相对 Set-Coverage >=0.03，paired 95% CI 下界 >0；MUR–Static gap 从 no-redundancy 到 high-redundancy 增加；duplicate-selection rate 至少相对下降 30%。
- **Failure interpretation**：若 coverage baseline 持平，novelty 收缩为 outcome-calibrated coverage；若 Static 持平，set-conditioning 主张失败并停止项目。
- **Target**：Figure 1A–B、Figure 3A–B、Table 3。
- **Priority**：MUST-RUN。

### B3: Gate C — stopping, harm, and calibration

- **Claim tested**：calibrated stopping 改善 gain–harm/cost frontier。
- **Dataset/task**：synthetic `K={8,16,32}`, `Bmax={1,2,4,8}`, harmful fraction `{0,.1,.25,.4}`，redundancy=.5。
- **Systems**：Pool-all、forced-B MUR-light、point-threshold MUR-light、interval MUR-light；Base-only 是 zero-gain/zero-harm origin。
- **Metrics**：prediction gain、NTR (`delta=0` primary; positive margins sensitivity)、average contexts、gain/context、certified-stop rate、uncertain-stop rate、interval coverage、wall clock。
- **Setup**：3 seeds；calibration alpha `{.05,.1,.2}`；test thresholds frozen before evaluation。
- **Success criterion**：interval MUR 在至少两个 harmful/K settings 相对 forced-B 形成严格 Pareto improvement；在 matched gain 下 NTR 相对下降 >=20% 或在 matched NTR 下 gain 提高 >=5%；deployed-prefix coverage shortfall <=3 percentage points after any permitted roll-in。
- **Failure interpretation**：若 point routing有效但 calibrated stopping无效，删除 stopping contribution；若 coverage shift 持续，停止 certificate language。
- **Target**：Figure 3C–D、Table 4。
- **Priority**：MUST-RUN。

### B4: Gate D — Electricity external decision task

- **Claim tested**：MUR 的 set-conditioned advantage超出 synthetic 构造，并在历史片段选择中改善预测/成本权衡。
- **Dataset/task**：UCI Electricity 2014。anchor 为目标 client 的短历史周与 query time；candidate pool 包含同 client 其他周、相似 client、不同 client 和 seasonal mismatch。主设定 `K=8,B<=2`。
- **Partitions**：在现有 client/time split 基础上重新生成四分区；client 与 week window 均不交叉。沿用 log1p normalization、Fourier time features 与 ridge expert，但任务改为 multi-candidate subset selection。
- **Systems**：Base-only、Similarity、Static Utility、MMR/Set-Coverage、MUR-light、Oracle Greedy；Pool-all 作为 harm reference。
- **Metrics**：test MSE、utility recovery、NTR、useful-selection precision、average contexts、latency、expert/router calls。
- **Setup**：smoke 后 3 seeds；每 seed 训练 labels >=32k、calibration >=8k、test >=16k episodes，最终数量由运行时间 gate 调整但 test 在冻结前确定。
- **Success criterion**：方向性顺序 `MUR-light > Static Utility > Similarity` 在 utility recovery 与 MSE improvement 上成立；MUR vs Static paired CI 排除 0；MUR NTR 不高于 Static，且端到端 gain-cost frontier 更优。
- **Failure interpretation**：若 MUR-full 成功而 MUR-light 失败，项目转为 counterfactual amortization；若两者均失败，不扩展 Traffic/Activity。
- **Target**：Table 2、Figure 4A、Figure 5 episode trace。
- **Priority**：MUST-RUN。

## Expansion Blocks After All Gates Pass

- **Traffic**：PEMS-SF 或等价多 sensor forecasting；严格 sensor/time split；候选来自 same sensor dates、neighbors、profile-similar and unrelated sensors。
- **Activity**：PAMAP2；subject-disjoint split；classification primary metric macro-F1/accuracy；候选来自 same/different subjects and sessions。
- 两者先做 1-seed feasibility，只有 oracle headroom、label reliability 与 MUR-light latency均通过才扩到3 seeds。

## Compute and Data Budget

- **Gate budget**：34–70 GPU-hours，优先单 A10G；第二张 A10G 只并行独立 seeds。
- **Expansion budget**：48–120 GPU-hours after go decision。
- **Offline labels**：每次 expert calls、cache bytes、wall time 单独记账；MUR-full 不得混入 MUR-light online cost。
- **Human evaluation**：无。
- **Biggest bottleneck**：Electricity multi-candidate label cache 与 MUR-light 对 nonlinear response 的可预测性。

## Risks and Mitigations

- **No oracle headroom**：停止该 dataset，不调整 router制造假提升。
- **Static utility sufficient**：终止 set-conditioned主张。
- **Coverage baseline sufficient**：收窄 novelty，检查 payoff heterogeneity 是否真实存在。
- **State shift**：按预注册阈值最多一次 roll-in，之后重新 calibration。
- **MUR-light fails, MUR-full works**：转为 amortized counterfactual utility story，重新评估成本和标题。
- **Calibration intervals too wide**：报告 risk–coverage，不能通过 test tuning 缩窄。
- **Pure complementarity**：作为失败案例；不临时加入 beam search。
