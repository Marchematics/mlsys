\section{State-Conditioned Context Selection}

Let $S_0$ denote the information that is always available to the predictor,
$x$ the current query, and $\candidates=\{C_1,\ldots,C_K\}$ the candidate
contexts. A selected set $A$ determines the prediction $f_A(x)$. The predictor
is trained before context selection and remains fixed while the selector makes
its decisions.

We measure the value of a selected set by the loss it removes relative to the
anchor-only prediction,
\begin{equation}
 F(A)=\E\!\left[\loss(f_{\emptyset}(x),y)-\loss(f_A(x),y)\right]
 -\lambda c(A),
\end{equation}
where $c(A)$ is an optional context cost. The value of adding candidate $j$ to
the current set is
\begin{equation}
 \marginal(j\mid A)=F(A\cup\{j\})-F(A).
 \label{eq:marginal}
\end{equation}
This is the quantity the selector ultimately needs. Its value can change after
each accepted context because the prediction $f_A(x)$ changes.

Training data provide a direct observation of that change. For an episode with
observed target $y$,
\begin{equation}
 \widetilde{\marginal}(j\mid A)
 =
 \loss(f_A(x),y)-\loss(f_{A\cup\{j\}}(x),y)-\lambda c_j .
 \label{eq:target}
\end{equation}
These observed marginals supervise the learned utility models used later.

Two oracle policies reveal how much value is created by updating candidate
scores. A standalone oracle ranks candidates by their true utility at the empty
set and keeps that order fixed. A sequential oracle recomputes the true
marginal after every addition. If their gains over the anchor-only predictor are
$G_{\mathrm{stand}}$ and $G_{\mathrm{seq}}$, we define
\begin{equation}
 H_{\mathrm{state}}
 =
 \frac{G_{\mathrm{seq}}-G_{\mathrm{stand}}}{G_{\mathrm{seq}}}.
 \label{eq:headroom}
\end{equation}
We call this ratio \emph{structural headroom}. It measures the opportunity
created by state-dependent candidate value. It says nothing yet about how much
of that opportunity a learned selector can recover from information available
before the target is observed. That second question is the focus of the theory
and experiments that follow.
