\section{Discussion}
\label{sec:discussion}

The results connect three parts of the same decision. Structural headroom
measures how much value can be created by updating candidate scores. Predictor
response determines how much of that value is visible before the outcome is
known. Pool geometry shapes which simple policy is sensible when a learned
ordering is weak.

\subsection{Structural opportunity and realizable value}

A large oracle gap can coexist with a weak learned selector. The strong
nonlinear predictors make this clear. Oracle gains remain substantial, yet
cached recall approaches its random reference, held-out utility prediction
loses explanatory power, and episode-level confidence signals carry almost no
information about whether routing will beat pooling. The opportunity survives;
the observable ordering signal does not.

The expert-strength and library-size sweeps reinforce the same mechanism.
Adapting the predictor removes systematic residual structure and sharply
reduces the value that routing can realize. Expanding the candidate library
raises the oracle opportunity while making the candidate ordering harder to
recover. Better prediction and richer candidate pools can therefore move the
selection problem in opposite directions.

\subsection{Why response is the right observation}

Under squared loss, the state-dependent part of utility is the alignment
between the candidate-induced response and the residual of the current
prediction. The Bregman identity and the cross-entropy bound extend this
geometry beyond squared error. The theory-shaped head improves ranking when the
signal is present, while alternative heads converge to the same ceiling when
the signal collapses. This agreement between theory and experiments gives the
response a clear role: it exposes the part of candidate value that content
features alone cannot represent.

\subsection{Pool geometry changes the value of relevance}

Relevance behaves differently as the candidate pool becomes more novel relative
to the anchor. Highly redundant candidates can amplify information the predictor
already has and reduce performance. Less redundant candidates add independent
signal, and relevance becomes useful. The novelty statistic captures this
transition within a deployment and supports a simple adaptive fallback between
retrieval and pooling.

The threshold is fitted within the deployment because the same novelty level
does not imply the same effect across datasets. What transfers is the mechanism:
candidate value depends on how much new information the pool can contribute to
the current predictor.

\subsection{Ranking and stopping solve different problems}

The demonstration-selection experiments separate candidate ordering from score
calibration. When standalone and sequential oracles are nearly identical,
dynamic ranking has little extra value under the natural stopping rule. Forcing
the budget exposes a clear ranking advantage. A selector can therefore lose
value because the candidate order is hard to identify or because the stopping
rule ends the sequence before ranking matters. These cases call for different
interventions.

\subsection{Deployment implications}

The practical workflow follows directly from the experiments. Measure the
available structural opportunity, check whether candidate utility is recoverable
from the state and predictor response, and then choose among response-aware
routing, a geometry-adaptive fallback and pooling. The pilot study shows that a
small labelled sample can make this decision reliably in clear cases. Temporal
shift preserves the direction of the effect better than its significance, so
marginal deployments should collect more pilot targets before committing to a
policy.

\subsection{Scope}

The general-loss theory describes the information carried by predictor response
while the state-dependent coefficient is still learned from outcomes. The
strong-predictor experiments cover a finite set of architectures, and the
second task family uses frozen CLIP representations. Other predictors may expose
different residual structure and should be evaluated with the same diagnostics.
The novelty threshold is deployment-specific. The regret result is local to one
selection step, matching the greedy decision analyzed in the paper.
