\section{Related Work}

Context selection has been studied most often through the content of the
candidates. Retrieval and demonstration-selection methods score examples by
similarity to the query or learn representations that support retrieval
\citep{brown2020language,min2022rethinking,liu2022what,rubin2022learning,zhang2022active,su2023selective}.
Diversity and coverage methods reduce redundancy in the selected set
\citep{carbonell1998use,gupta-etal-2023-coverage,levy2023diverse}, while recent
retrieval systems adapt the acquisition process to the query or the evolving
reasoning state \citep{acra2025retrieval,crgs2026causal}. These methods decide
which information looks relevant or complementary. Our setting asks a more
specific predictive question: how much will one additional context improve the
prediction that the selected set already produces?

Outcome-aware methods move closer to that question by valuing information
through its effect on model output. Incremental-utility selection estimates the
benefit of a demonstration relative to an empty context
\citep{hashimoto-etal-2024-take}. Data valuation and influence methods assign
credit to examples through their effect on predictions
\citep{ghorbani2019data,koh2017understanding,pruthi2020estimating,ilyas2022datamodels}.
These ideas motivate predictive utility as a selection signal. State-conditioned
marginal utility extends the same principle to a nonempty selected set, where
the value of a candidate can change after every accepted addition.

Set selection provides the structural language for that dependence. Submodular
objectives model coverage and diminishing returns
\citep{lin2011class,nemhauser1978analysis,krause2014submodular}, determinantal
point processes model diverse subsets \citep{kulesza2012determinantal}, and
adaptive submodularity studies sequential acquisition
\citep{golovin2011adaptive,leskovec2007cost}. These objectives are useful when
the set value is known from content or task structure. In predictive context
selection, the relevant set value is the loss of a fixed predictor, and an
additional context can either reduce or increase that loss. This connects the
problem to negative transfer and selective information use
\citep{pan2010survey,wang2019characterizing}.

Learned routing treats selection as a decision problem. Mixture-of-experts
models choose computational components
\citep{jacobs1991adaptive,shazeer2017outrageously,zhou2022mixture,fedus2022switch},
and routing networks adapt computation across tasks
\citep{rosenbaum2018routing,ma2018modeling}. Recent systems extend dynamic
routing to language, multimodal and collaborative settings
\citep{failuremode2026routing,dream2026routing,cogmoe2026sparse}.
Decision-focused learning links prediction quality to the downstream decision
that consumes it
\citep{bertsimas2020predictive,elmachtoub2022smart,wilder2019melding,mandi2024decision,donti2017task},
while sequential decision methods study how information gathered now changes
later choices \citep{auer2002finite,dudik2011doubly}. Our contribution fits
this line at the level of auxiliary context: the fixed predictor stays unchanged
during selection, and the selector learns the marginal effect of each candidate
from the predictor response and the current selected state.
